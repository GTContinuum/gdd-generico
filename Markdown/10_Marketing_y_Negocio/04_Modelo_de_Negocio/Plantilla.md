# Modelo de negocio

Esta ficha explora cómo podría sostenerse y venderse el juego, de acuerdo con su público y alcance. Premium significa pagar una vez; free-to-play permite empezar gratis; DLC significa contenido descargable; expansiones, suscripción, anuncios o compras dentro de la aplicación son opciones que solo aplican si encajan. Úsala para comparar decisiones, no para imponer una fórmula.
