# GDD genérico

Una estructura modular para documentar el diseño, la producción y el lanzamiento de un videojuego. Está pensada para estudiantes, equipos independientes y estudios nuevos que necesitan convertir una idea en decisiones claras y comprobables.

No es necesario completar todas las fichas. Elige únicamente los documentos que ayuden a resolver una pregunta o comunicar una decisión de tu proyecto.

## Cómo empezar

1. Lee la [Guía de inicio](00_Indice_y_Control/02_Guia_de_Inicio.md).
2. Usa el [Índice general](00_Indice_y_Control/01_Indice_General.md) para elegir las áreas que necesita tu juego.
3. Duplica las fichas `Plantilla.md` que vayas a completar y renómbralas de forma clara.
4. Mantén responsables, fechas, estados y decisiones importantes al día.

Markdown es la fuente editable de este repositorio. Los enlaces son relativos para que la documentación siga funcionando al clonar, descargar o reutilizar la estructura.
